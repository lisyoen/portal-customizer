<h1 align="center">Portal Customizer</h1>

<p align="center">사내 포털·대시보드 화면을 내 마음대로. 화면의 위젯을 자동으로 찾아 끌어 옮기고, 컬럼 폭을 바꾸고, 이미지·링크·메모·웹페이지 패널을 더합니다.</p>

<p align="center"><a href="README.md">English</a> · <b>한국어</b></p>

## 어떻게 동작하나요

Portal Customizer 는 화면을 만든 프론트엔드 프레임워크의 컴포넌트 구조를 읽어 위젯(패널·카드·로우)을 찾습니다.

| 화면 | 위젯을 찾는 방법 |
|------|------------------|
| Vue 3 | 앱의 vnode 트리(운영 빌드 포함)에서 컴포넌트 인스턴스의 루트 요소 |
| Vue 2 | 컴포넌트 루트 요소(`__vue__`) |
| React | Fiber 트리에서 컴포넌트의 첫 DOM 요소 |
| Angular·웹 컴포넌트 | 사용자 정의 태그(`app-card` 등) |
| 그 밖의 화면 | 화면 구조(나란히 놓인 박스와 그 안에 쌓인 박스) |

찾은 위젯 가운데 여러 컬럼에 걸쳐 가장 넓은 영역을 차지하는 묶음을 꾸밀 영역으로 고르고, 위젯을 컬럼별로 나눕니다. 화면을 처음 편집할 때 관리자가 위젯 단위를 확인합니다. 찾은 위젯이 화면 위에 테두리로 표시되고, **더 크게(상위) / 더 작게(하위)** 로 단위를 바꾸거나 **견본 위젯 고르기** 로 위젯 하나를 누르면 같은 단계의 위젯을 함께 찾습니다. 정한 위젯 단위는 배치와 함께 관리 서버로 전송되므로 선택자를 직접 쓸 필요가 없습니다.

원래 위젯은 화면의 프레임워크가 계속 그리고 움직입니다. Portal Customizer 는 위젯을 옮기지 않고 보이는 위치만 정하므로, 위젯의 버튼·갱신·클릭은 그대로 동작합니다.

## 기능

| 기능 | 설명 |
|------|------|
| 화면별 꾸미기 | 팝업의 **이 화면 꾸미기** 로 켭니다. 처음 한 번 그 사이트 접근을 허용하며, 배치는 화면 주소마다 따로 저장됩니다. 팝업에 감지한 프레임워크와 위젯 수가 표시됩니다. |
| 편집 모드 | 관리 서버에 관리자로 로그인하면 나타납니다. 켜면 화면에 편집 도구막대가 나타납니다. |
| 끌어놓기 | 위젯을 다른 컬럼으로 옮기거나 순서를 바꿉니다. 컬럼 머리를 끌면 컬럼 순서가 바뀝니다. |
| 크기·간격 | 컬럼 경계로 폭, 패널 아래 경계로 높이를 바꿉니다. 패널·컬럼 간격을 개별로 또는 기본값으로 정합니다. |
| 위젯 | 화면 위젯을 그대로 두거나 숨기거나 뺄 수 있고, 위젯 제목을 숨길 수 있습니다. 화면이 위젯을 다시 그리거나 늦게 그려도 다시 찾아 배치합니다. |
| 추가 패널 | 이미지, 링크 모음(목록·배너), 메모, 웹 페이지, 동영상, 하이퍼텍스트(HTML, 위험한 태그 제거), 캐러셀, 탭 피드(같은 사이트 게시판 글 모으기). |
| 관리 서버 | 관리자용 서버(선택): 확장에서 배치 전송, 기본·예약 배치 게시, 적용할 화면 주소 지정, 콘텐츠(CMS), 사용 통계, 확장 배포. [server/README.md](server/README.md) |
| 조직 기본 배치 | 관리 서버(또는 웹서버)의 배치 파일 주소를 넣으면 그 파일이 지정한 화면들이 기본 배치로 시작하고 변경도 자동 반영됩니다. |
| 내보내기·가져오기 | 배치를 JSON 으로 저장하고 다시 불러옵니다. |
| 원클릭 업데이트 | 관리자가 관리 서버 **확장 배포** 에 새 버전을 올리면 아이콘에 **NEW** 가 표시되고 팝업에서 한 번 눌러 설치합니다. |

## 설치

개발자 모드로 설치합니다(Chrome, Edge 등 Chromium 브라우저).

1. [Releases](https://github.com/lisyoen/portal-customizer/releases/latest) 에서 `portal-customizer-vX.Y.Z.zip` 을 받아 폴더에 풉니다.
2. `chrome://extensions`(또는 `edge://extensions`)에서 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다** 로 그 폴더를 고릅니다.
3. 업데이트 도우미를 한 번 등록합니다. Windows: `updater\install-updater.bat` 더블클릭 / macOS·Linux: `bash updater/install-updater.sh`

## 사용법

1. 꾸밀 화면을 열고 Portal Customizer 아이콘을 눌러 **이 화면 꾸미기** 를 누릅니다.
2. 관리자로 로그인한 뒤 **편집 모드** 를 켭니다. 화면의 위젯이 컬럼별로 잡혀 나타납니다.
3. 위젯 제목 막대를 끌어 옮기고, 도구막대의 **+ 패널**, **+ 컬럼** 으로 추가하고, ⚙ 로 설정합니다.
4. **저장**(Ctrl+S)을 누릅니다. **원래 배치** 는 화면의 원래 배치에서 다시 시작합니다.

팝업에서 **이 화면 꾸미기 끄기** 나 **사용** 스위치를 끄면 언제든 원래 화면으로 돌아갑니다.

## 조직 기본 배치

관리 서버 **설정·업데이트 > 적용할 화면** 에 화면 주소(이 주소로 시작하는 화면, `*` 는 아무 글자)를 넣고 배치를 게시합니다. 직원은 팝업 **사내 기본 배치** 에 `http://서버:포트/portal-customizer.json` 을 넣습니다. 파일 형식은 [docs/layout-format.md](docs/layout-format.md).
