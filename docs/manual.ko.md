# Portal Customizer 관리자 매뉴얼

Portal Customizer 는 포털·대시보드 화면의 위젯을 찾아 배치를 바꾸는 브라우저 확장과, 사내에 배치를 배포하는 관리 서버로 이루어집니다. 이 매뉴얼은 관리자 기준으로 설치부터 배포·운영까지를 설명합니다.

## 1. 전체 흐름

1. 관리 서버를 설치합니다.
2. 관리자가 꾸밀 화면에서 팝업의 **이 화면 꾸미기** 를 누르고, 관리자로 로그인한 뒤 편집 모드로 화면을 꾸며 관리 서버로 전송합니다.
3. 관리 페이지에서 기본 배치와 기간별 배치, 배치를 적용할 화면 주소를 정합니다.
4. 직원들의 확장은 `portal-customizer.json` 을 주기적으로 받아, 지금 노출할 배치를 화면에 적용합니다.

## 2. 관리 서버 설치

필요한 것: Linux, Node.js 18 이상, git, PM2(없으면 설치 스크립트가 설치합니다). GitHub 에 접속할 수 없는 서버는 다른 곳에서 받은 오프라인 업데이트 패키지로 올립니다.

```bash
curl -fsSL https://raw.githubusercontent.com/lisyoen/portal-customizer/main/server/scripts/install.sh | bash -s -- --port 포트 --url http://서버주소:포트
```

- 처음 설치할 때 관리자 `admin` 의 비밀번호(8자 이상)를 두 번 입력합니다.
- 소스는 `~/portal-customizer-server`, 데이터는 그 아래 `server/data/` 에 저장됩니다.
- 이미 설치된 서버에서 같은 명령을 다시 실행하면 데이터는 그대로 두고 최신 버전으로 올라가며, 포트와 주소 설정이 바뀝니다.
- 재부팅 후 자동 실행이 필요하면 `pm2 startup` 과 `pm2 save` 를 한 번 설정합니다.
- 관리자를 명령줄에서 추가하거나 비밀번호를 재설정하려면: `PC_PASSWORD=비밀번호 node cli.js admin 아이디` (`~/portal-customizer-server/server` 에서 실행)

설치 후 주소:
- 관리 페이지: `http://서버주소:포트/`
- 직원 배포 주소: `http://서버주소:포트/portal-customizer.json`

## 3. 확장 설치와 관리자 로그인

1. 확장을 설치합니다(설치 방법은 README 참고). 업데이트는 관리 서버(**확장 배포** 메뉴)에서만 받습니다(16장).
2. 확장 아이콘을 눌러 팝업 아래쪽 **관리자 로그인** 에 관리 서버 주소, 아이디, 비밀번호를 넣습니다.
3. 로그인하면 팝업에 **편집 모드** 스위치와 관리자 기능(관리 서버로 전송, 관리 페이지 열기, 사내 기본 배치로 사용, 로그아웃)이 나타납니다.

편집 모드는 관리자로 로그인한 경우에만 사용할 수 있습니다. 로그아웃하거나 로그인이 만료되면 편집 모드는 바로 꺼집니다.

## 4. 꾸밀 화면 켜기와 위젯 감지

1. 꾸밀 화면을 열고 확장 아이콘을 눌러 **이 화면 꾸미기** 를 누릅니다. 처음 한 번 그 사이트 접근 허용 창이 뜹니다.
2. 팝업의 **이 화면** 에 화면 주소와 "감지: 프레임워크 · 위젯 N개" 가 표시됩니다. Vue·React·Angular 화면은 컴포넌트 단위로, 그 밖의 화면은 화면 구조로 위젯을 찾습니다.
3. 배치는 화면 주소(쿼리 제외)마다 따로 저장됩니다. **이 화면 꾸미기 끄기** 를 누르면 원래 화면으로 돌아갑니다.

관리자가 화면을 처음 편집하면 **위젯 단위 정하기** 막대가 먼저 나타납니다.

- 자동으로 찾은 위젯이 화면 위에 파란 테두리와 번호로 표시되고, 막대에 위젯 수가 나옵니다.
- **더 크게(상위)**: 위젯을 한 단계 위의 묶음으로 잡습니다(예: 카드 대신 카드가 든 컬럼).
- **더 작게(하위)**: 한 단계 아래로 잡습니다.
- **견본 위젯 고르기**: 누른 뒤 위젯으로 삼을 요소를 클릭하면 같은 단계의 다른 위젯을 함께 찾습니다.
- **자동으로**: 자동 감지 결과로 되돌립니다. **적용** 하면 그 단위로 편집기가 열립니다.

정한 위젯 단위는 이 화면에 저장되고, 배치를 저장해 관리 서버로 보내면 배치와 함께 직원들에게 배포됩니다. 편집 중에는 도구막대의 **▣ 위젯 단위** 로 다시 열 수 있으며, 단위를 바꾸면 편집 중인 배치는 화면의 원래 모양에서 다시 시작합니다.

## 5. 배치 만들기 (확장 편집 모드)

편집 모드를 켜면 꾸미기를 켠 화면 위에 편집 도구막대가 나타나고, 감지한 위젯이 컬럼별로 잡혀 나타납니다.

- **패널 이동**: 패널 제목 막대를 끌어 다른 위치나 다른 컬럼으로 옮깁니다.
- **크기**: 컬럼 오른쪽 경계를 끌어 폭을, 패널 아래 손잡이를 끌어 높이를 바꿉니다.
- **간격**: 패널 제목 막대의 ↕ 숫자칸이나 점선 띠로 세로 간격을, 컬럼 사이 숫자로 가로 간격을 바꿉니다. 도구막대의 **↕ 간격** 에서 기본값을 정합니다.
- **패널 추가**: 화면 위젯, 이미지, 동영상, 하이퍼텍스트, 링크(목록·배너), 메모, 웹페이지(iframe), 캐러셀, 게시판 피드를 추가할 수 있습니다. 패널마다 톱니바퀴로 설정을 엽니다.
- **사내 기본**: 관리 서버에서 지금 노출 중인 배치를 다시 받아 편집기에 불러옵니다.
- **원래 배치**: 화면의 원래 배치로 되돌립니다.
- **내보내기 / 가져오기**: 배치를 JSON 파일로 저장하거나 불러옵니다.
- **저장** 하면 편집 모드가 끝나고 화면에 적용됩니다. **취소** 하면 변경 내용은 버려집니다.

## 6. 관리 서버로 전송

팝업의 **관리 서버로 전송** 에 이름을 넣고 전송하면, 지금 화면에 쓰는 배치가 관리 서버의 배치 목록에 추가됩니다. 패널에 직접 올린 이미지는 서버 파일로 옮겨집니다.

## 7. 배치 목록과 노출 규칙

관리 페이지 **배치** 에서 전송된 배치를 관리합니다.

- **기본 배치**: 1개를 고르면 목록 맨 위로 올라갑니다. 예약된 배치가 없는 시간에 노출됩니다.
- **예약 배치**: 공개 시작·종료 일시를 넣으면 그 기간에 노출됩니다.
- **노출 규칙**: 공개 기간 중인 예약 배치가 기본 배치보다 먼저 노출됩니다. 기간이 겹치면 목록에서 위에 있는 배치가 노출됩니다. 예약 배치가 없는 시간에는 기본 배치가 노출됩니다.
- **우선순위**: ▲▼ 로 순서를 바꿉니다.
- **사용/중지, 복사, 삭제** 를 할 수 있습니다.
- 목록 위의 일정 막대에서 앞으로 30일 동안 어떤 배치가 노출되는지 확인합니다.

## 8. 배치 편집 (관리 페이지)

배치 이름을 누르면 편집 화면이 열립니다.

- 컬럼과 패널의 설정(제목, 크기, 간격, 패널별 내용)을 바꿉니다.
- 이미지·동영상은 그 자리에서 업로드하거나 **CMS** 버튼으로 등록된 콘텐츠를 고릅니다.
- **JSON 보기** 로 배치 원본을 확인합니다.
- **변경 이력** 에서 예전 상태로 되돌립니다.
- 화면 배치를 끌어서 바꾸는 작업은 확장의 편집 모드에서 합니다.

## 9. 콘텐츠 (CMS)

**콘텐츠(CMS)** 에서 그룹별로 이미지, 동영상, 텍스트, 하이퍼텍스트, 링크를 등록하고 태그로 찾습니다. 등록한 콘텐츠는 배치 편집 화면에서 골라 패널에 넣을 수 있습니다. 하이퍼텍스트의 스크립트와 위험한 링크는 자동으로 제거됩니다.

## 10. 통계

**통계** 에서 일별 사용자 수와 요청 수, 노출된 배치, 확장 버전 분포를 봅니다. 사용자 수는 확장이 보내는 익명 설치 식별값으로 세며, 개인 정보는 수집하지 않습니다.

## 11. 관리자·감사 로그

관리자 권한을 가진 사람만 볼 수 있습니다.

- 관리자 추가, 역할(관리자/편집자) 지정, 비밀번호 재설정, 계정 중지
- 편집자는 배치·콘텐츠를 다룰 수 있지만 관리자 관리와 서버 설정·업데이트는 할 수 없습니다.
- 감사 로그에 로그인, 배치 변경, 설정 변경, 업데이트 같은 작업 기록이 남습니다.

## 12. 설정

- **서버 주소**: 업로드 파일 주소를 만들 때 씁니다. 비우면 접속한 주소를 씁니다.
- **이름**: 관리 화면 왼쪽 위 제목, 로그인 화면 제목, 브라우저 탭 제목에 표시됩니다.
- **새 버전 자동 업데이트 / 확인 주기(분)**: 기본값은 1분마다 확인입니다.
- **적용할 화면**: 배치를 적용할 화면 주소를 한 줄에 하나씩 넣습니다. 이 주소로 시작하는 화면에 적용되고 `*` 는 아무 글자입니다(예: `https://portal.example.com/home`). 비워 두면 어느 화면에도 적용되지 않습니다. 위젯 단위는 서버에서 정하지 않고, 관리자가 확장 편집 모드에서 정해 배치와 함께 보냅니다.
- **직원 확장이 배치를 다시 확인하는 주기(분)**: 기본값은 5분입니다. `portal-customizer.json` 에 `refreshMinutes` 로 함께 배포됩니다. 짧을수록 빨리 반영되지만 요청이 늘어납니다. 직원이 팝업에서 직접 주기를 넣으면 그 값이 우선합니다.

## 13. 업데이트

- 관리 화면 왼쪽 위 제목 아래에 현재 버전, 업데이트 버튼, 릴리스 노트 링크가 있습니다.
- **온라인**: 서버가 GitHub 의 새 버전을 확인해 자동으로 적용합니다. 새 버전으로 바꾸고 재시작한 뒤 응답을 확인하며, 실패하면 이전 버전으로 되돌립니다.
- **오프라인**: GitHub 릴리스 페이지의 `portal-customizer-server-update-버전.tar.gz` 를 받아 **설정·업데이트** 에서 올립니다.
- 관리 페이지를 열어 둔 채 서버가 업데이트되면, 1분 안에 페이지가 스스로 새로고침되어 새 메뉴가 나타납니다. 배치 편집 중 저장하지 않은 변경이 있으면 새로고침하지 않고 안내만 띄우므로, 저장한 뒤 새로고침하세요.

## 14. 백업·복원

**설정·업데이트** 에서 데이터(배치, 콘텐츠, 관리자, 통계, 업로드 파일)를 백업 파일로 내려받고, 백업 파일로 복원합니다. 복원 직전 상태는 서버 데이터 폴더에 따로 보관됩니다. 배치·콘텐츠 어디에도 쓰이지 않는 파일은 한 번에 지울 수 있습니다.

## 15. 직원 배포

- 직원은 확장 팝업의 **사내 기본 배치** 에 배포 주소(`http://서버주소:포트/portal-customizer.json`)를 넣고 **불러오기** 를 누릅니다. 배치는 **적용할 화면** 에 넣은 화면에만 적용되며, 그 화면의 사이트 접근 허용이 필요합니다.
- 관리자는 팝업의 **사내 기본 배치로 사용** 을 누르면 로그인한 서버의 배포 주소가 자동으로 들어갑니다.
- 회사가 브라우저 정책을 관리한다면 `orgConfigUrl` 정책으로 모든 직원의 주소를 한 번에 지정할 수 있습니다.

## 16. 확장 배포와 업데이트 받을 곳

확장 업데이트는 관리 서버 업데이트와 따로 합니다. 확장 새 버전이 나와도 관리 서버를 올릴 필요가 없습니다.

1. GitHub 릴리스에서 `portal-customizer-vX.Y.Z.zip` 을 받습니다.
2. 관리 페이지 **확장 배포** 에서 변경 내용을 적고 **zip 파일 선택해서 올리기** 를 누릅니다. **올리면서 바로 배포** 를 끄면 올리기만 하고, 나중에 목록의 **이 버전 배포** 로 배포합니다.
3. 직원 확장은 업데이트 확인 때(약 1분마다) 새 버전을 알아채고, 팝업의 **업데이트** 버튼으로 설치합니다.

- 문제가 있으면 목록에서 이전 버전을 **이 버전 배포** 로 되돌리거나 **배포 중지** 합니다. 이미 새 버전을 설치한 확장은 되돌아가지 않습니다.
- 확인 주소는 `http://서버주소:포트/ext/latest.json` 입니다.
- 확장 패키지는 백업 파일에 포함되지 않습니다. 복원 후에는 다시 올립니다.

**업데이트 받을 곳 (확장 팝업)**
- 확장은 관리 서버에서만 업데이트를 받습니다. 사내 기본 배치 주소의 관리 서버를 쓰고, 주소가 없으면 관리자로 로그인한 서버를 씁니다. 팝업의 **업데이트 받을 곳** 줄에 서버 주소가 표시됩니다.
- 사내 기본 배치 주소도 관리자 로그인도 없으면 업데이트를 확인하지 않습니다. 이때는 팝업에 "사내 기본 배치 주소(관리 서버)가 없습니다" 가 표시됩니다.

## 17. 라이선스

Portal Customizer 은 BSL 1.1 로 소스를 공개합니다. 사내 사용은 무료이고, 다른 회사에 상품이나 유료 서비스로 제공하려면 상업 라이선스가 필요합니다. 자세한 내용은 관리 페이지의 **라이선스** 메뉴를 보세요.
