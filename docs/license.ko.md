# 라이선스 안내

Portal Customizer(브라우저 확장과 관리 서버)은 **Business Source License 1.1(BSL 1.1)** 로 소스를 공개합니다. 소스 코드는 누구나 보고, 고치고, 공유할 수 있습니다. 다만 다른 회사에 상품이나 유료 서비스로 제공하는 것은 저작자에게 상업 라이선스를 받은 사업자만 할 수 있습니다.

BSL 1.1 은 OSI 가 인정하는 "오픈소스" 라이선스가 아니라 "소스 공개(source-available)" 라이선스입니다. 각 버전은 공개일로부터 4년이 지나면 Apache License 2.0 으로 자동 전환됩니다.

전문은 [LICENSE](https://github.com/lisyoen/portal-customizer/blob/main/LICENSE) 파일에 있습니다. 이 안내는 이해를 돕기 위한 요약이며, 내용이 다르면 LICENSE 전문이 우선합니다.

## 한눈에 보기

| 하고 싶은 일 | 가능 여부 |
|---|---|
| 우리 회사(조직) 안에서 설치해 운영 | 무료로 가능 |
| 소스를 고쳐서 우리 회사 안에서 사용 | 무료로 가능 |
| 고친 소스를 같은 라이선스로 공개·공유(fork) | 가능 |
| 임직원·우리 회사를 위해 일하는 개인 계약자의 사용 | 사내 사용으로 봅니다 |
| 다른 회사에 상품으로 판매·라이선스·배포 | 상업 라이선스 필요 |
| 다른 회사에 유료 설치·커스터마이징·지원 제공 | 상업 라이선스 필요 |
| 다른 회사에 호스팅(SaaS·관리형 서비스)으로 제공 | 상업 라이선스 필요 |

## 자주 묻는 질문

**회사가 직접 설치해서 쓰는 것도 돈을 내야 하나요?**
아니요. 각 회사가 자기 조직 안에서 직접 설치하고 운영하는 것은 무료입니다.

**외부 업체에 설치를 맡기면요?**
그 업체가 돈을 받고 설치·커스터마이징·지원을 해 주는 것은 상업적 제공입니다. 그 업체가 상업 라이선스를 받아야 합니다.

**고친 버전을 GitHub 에 올려도 되나요?**
됩니다. 단, 같은 BSL 1.1 라이선스와 LICENSE 파일을 그대로 함께 두어야 합니다.

**4년 뒤에는 어떻게 되나요?**
각 버전은 공개일로부터 4년이 지나면 Apache License 2.0 으로 바뀌어, 상업적 이용도 자유로워집니다. 그 뒤에 나온 새 버전은 다시 각자의 공개일로부터 4년 동안 BSL 1.1 입니다.
