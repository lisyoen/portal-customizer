# Contributing

Portal Customizer does not accept outside contributions. Pull requests from people other than the maintainer are closed without review.

You are welcome to:

- open an issue to report a bug or suggest an improvement;
- fork the repository and change it for your own organization under the terms of the [LICENSE](LICENSE) (Business Source License 1.1).

## 한국어

Portal Customizer 는 외부 기여(Pull Request)를 받지 않습니다. 관리자 외의 사람이 보낸 Pull Request 는 검토 없이 닫습니다.

- 버그 신고나 개선 제안은 이슈로 남겨 주세요.
- 자기 조직에서 쓰려고 fork 해서 고치는 것은 [LICENSE](LICENSE)(Business Source License 1.1) 조건 안에서 자유롭습니다.
